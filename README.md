# Project Title
DATA QUALITY INSPECTOR
## Project Description
 Data Quality Inspector aims to detect and manage data quality issues and recommend suitable improvements. Datasets may contain missing values, duplicate records, inconsistent categories, invalid entries, and unusual numerical values. Identifying these issues manually can be difficult and time-consuming, potentially leading to unreliable analyses and decisions.
 The project will provide a user-friendly website that helps users inspect, clean, and improve the quality of their datasets. If the available data is insufficient, the system may also suggest initiating a new data collection process when necessary.
## Objective
 The main objective is to develop a web-based system that evaluates dataset quality, detects common data issues, and recommends appropriate cleaning actions. Users will be able to review and approve suggested changes before they are applied. The system will also generate data quality reports and allow users to compare quality measurements before and after cleaning.
## Target Users
 The target users are students, researchers, and data analysts who work with structured datasets. The system is particularly intended for users who want to inspect and clean their data without writing complex code or using advanced data analysis tools.

## Planned Features
- Upload structured datasets in CSV or Excel format.
- Detect common data quality issues, such as missing values, duplicate records, and inconsistent categories.
- Identify potentially unusual numerical values for user review.
- Suggest possible data cleaning actions.
- Allow users to review proposed changes before applying them.
- Provide a summary of data quality before and after cleaning.
- Identify when the available data may be insufficient and suggest whether additional data collection is needed.
### In Scope
- Initial support for structured CSV and Excel datasets.
- Detection and reporting of common data quality issues.
- Suggested cleaning actions that users can review.
- A basic data quality summary.
### Out of Scope (Initial Version)
- Real-time data processing.
- Distributed or big-data processing.
- Advanced machine-learning-based automatic correction.
- Automatic collection from external sources before the data sources and method are defined.
