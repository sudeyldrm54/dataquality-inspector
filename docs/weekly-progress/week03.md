## Design Overview
The proposed system consists of a user interface, file handling component, error message handling component, data quality analysis component, report generation component, and cleaning and comparison component.
The design focuses on detecting common data quality issues and presenting results and cleaning suggestions to the user. Cleaning actions are intended to require user approval, while the original dataset remains unchanged.
